# Birthday Countdown 🎂

Página web de cuenta atrás para el próximo cumpleaños, creada con HTML, CSS y JavaScript puro.

## Ejecutar

1. Descomprime `birthday-countdown.zip`.
2. Abre `index.html` en tu navegador.

No requiere Node.js, instalación de dependencias ni servidor. La fuente Poppins se carga desde Google Fonts; si no hay conexión, se usará una fuente sans-serif alternativa.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño responsive y decoración.
- `script.js`: cálculo de la cuenta atrás y actualización cada segundo.
